# Modules

`cyclicpeptide` is composed of 8 primary submodules:

- [**IOManager**](IOManager.md): Plotting and file input/output (SVG, PDF, MOL, PDB).
- [**Sequence2Structure**](Sequence2Structure.md): Build peptide structures (SMILES/Mol) from sequences.
- [**Structure2Sequence**](Structure2Sequence.md): Identify amino acid units in a structure and derive sequence(s).
- [**SequenceTransformer**](SequenceTransformer.md): Detect and interconvert sequence formats.
- [**StructureTransformer**](StructureTransformer.md): Structure format conversions and 3D conformer generation.
- [**PropertyAnalysis**](PropertyAnalysis.md): Calculate physicochemical properties, drug-likeness rules, and fingerprints.
- [**GraphAlignment**](GraphAlignment.md): Graph-based alignment and similarity calculation.
- [**SequenceGeneration**](SequenceGeneration.md): Generate similar peptide sequences via mutation/substitution rules.
